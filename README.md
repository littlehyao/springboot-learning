# springboot-learning

*本项目以学习 Spring Boot 为主，包含和一些第三方框架的集成。*

</div>

---

## 项目说明

- 使用 Maven 模块化开发，每个模块一个功能，方便区分学习，也方便维护和扩展
- 基于 SpringBoot 4.x，JDK 版本为 17，相关版本和编译通过父 pom 统一管理
- 本项目以代码学习为主，不涉及项目构建部署
